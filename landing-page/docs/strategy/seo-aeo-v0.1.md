# A5 — SEO / AEO Direction v0.1

**Status:** Initial recommendation

## Indexing

Recommendation:
**Index the evergreen Basic Diet landing page.**

Reason:
- it represents the core offer,
- it can support branded and local discovery,
- it is not a temporary campaign-only page.

Campaign-specific variants may later use `noindex` when they are ad-only or temporary.
