# Component & Layout Specification v1.0

**Status:** COMPLETE

## Global layout

RTL.

Container:
- max 1200px
- desktop padding 24–32px
- mobile 16px

Grid:
- desktop 12 columns
- tablet 8 columns
- mobile 4 columns

Section spacing:
- desktop 80–96px
- mobile 48–64px

## Header
Desktop floating pill:
- logo right
- nav center
- CTA left

Mobile:
- logo
- CTA
- hamburger

States:
default, scrolled, open, focus.

## Hero
Desktop:
- text right 5 cols
- video left 7 cols

Mobile:
- video first
- copy below

Elements:
- headline
- subheadline
- primary CTA
- proof line

No pricing in hero.

## Value strip
Desktop: 4 items row.  
Mobile: 2×2.

Each:
- icon
- short label
- one factual detail

## Meal card
- image
- meal name
- optional verified nutrition fact
- optional category chip

No cart button.

## Tagline reveal
Standalone type section.  
Max width 680px.  
No card container.

## Benefits
4 benefit cards.

Each:
- icon
- short headline
- 1–2 lines
- concrete proof/detail

## How it works
3 steps only:
- number
- icon/visual
- title
- short explanation

Desktop 3 columns.  
Mobile vertical.

## App showcase
Green section.

- one main phone
- 2–4 supporting screens
- text opposite

Mobile:
- text
- screens
- CTA

No fake UI.

## Plan cards
Three:
- 7 days
- 26 days
- 30 days

Each:
- duration
- use-case line
- flexibility note
- CTA
- optional verified price later

No huge comparison matrix.  
No “Most Popular” badge without evidence.

## Review cards
2–4 max.

- short quote
- source/name only if approved
- no fake avatar

## FAQ
8 questions max.

Must be:
- semantic button
- keyboard accessible
- focus-visible

## Final CTA
Green background.

- closing headline
- supporting line
- same primary CTA
- optional store badges

## Footer
Dark/green/ink.

- white logo
- navigation
- contact/social
- privacy
- terms
- copyright
