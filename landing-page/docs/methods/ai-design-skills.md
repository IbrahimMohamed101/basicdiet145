## Adoption decision

We are using the skill as a **structured design process**, not as a template.

Order adopted:
1. A1 Intake
2. A2 Page structure
3. A3 Layout selection
4. A4 Conversion rules
5. A5 Copy
6. A6 Build section by section
7. A7 SEO / AEO
8. Part B visual system after strategy is sufficiently stable

## Rules adopted now

- one offer,
- one audience focus,
- one primary action,
- proof close to claims,
- objections treated as part of the page,
- mobile priority,
- section-by-section implementation,
- real content instead of filler.

## Project-specific overrides

### Arabic typography

The skill's approved font list is Latin-oriented and is not binding for this Arabic-first project.

We will choose an Arabic-capable font based on:
- readability,
- weight availability,
- web performance,
- brand fit,
- Arabic/Latin consistency.

### Copy punctuation

The skill's blanket "no hyphens" rule is treated as a stylistic preference, not a hard functional rule for Arabic copy.

### Visual rules

No Part B value is considered final until:
- real Basic Diet assets are reviewed,
- the visual direction is selected,
- Arabic/mobile behavior is validated.

## Why this method fits the project

The project intentionally separates:
`research → strategy → structure → visual system → implementation`

That is aligned with the skill's core principle: finish Part A before touching Part B.
