# Basic Diet Landing Page

هذا المجلد هو **مركز الحقيقة (Single Source of Truth)** الخاص ببناء Landing Page لـ Basic Diet.

## الهدف

نبني الصفحة على مرحلتين واضحتين:

1. **Research & Strategy**: جمع البيانات، تحليل المنافسين، فهم العميل، تحديد الرسائل والـCTA والهيكل البصري.
2. **Implementation**: يبدأ فقط بعد أن يصل التصور إلى نسخة معتمدة بما يكفي للتنفيذ.

> لا نبدأ بالكود لمجرد وجود Template جاهز. كل قرار مهم يجب أن يكون موثقًا أولًا.

## المرحلة الحالية

**Research & Direction — قيد العمل**

حتى الآن نركز على:
- تحليل المنافسين في سوق الوجبات الصحية بالسعودية.
- جمع صور وبيانات Basic Diet الحقيقية.
- تحديد القيمة الأساسية والاعتراضات والـCTA.
- بناء Landing Page Blueprint تدريجيًا.
- تسجيل كل قرار ومعلومة جديدة هنا.

## الملفات الأساسية

- `PROJECT_PROTOCOL.md` — طريقة العمل بيننا وكيف يتم تحديث المشروع.
- `docs/STATUS.md` — الحالة الحالية وما تم وما هو التالي.
- `docs/research/competitors.md` — تحليل المنافسين والمراجع.
- `docs/strategy/blueprint.md` — الهيكل المقترح للصفحة، يتطور مع البحث.
- `docs/data/data-checklist.md` — البيانات والأصول التي نحتاج جمعها.
- `docs/decisions/decision-log.md` — القرارات المعتمدة وأسبابها.
- `docs/playbook/landing-page-playbook.md` — قواعد التصميم والـCRO التي سنعتمد عليها.
- `implementation/README.md` — بوابة بدء التنفيذ الفعلي لاحقًا.

## قاعدة العمل

أي معلومة أو قرار جديد يمر بهذا المسار:

`Raw Data → Finding → Decision/Hypothesis → Update Blueprint → تنفيذ لاحقًا`

نفرق دائمًا بين:
- **FACT**: معلومة مؤكدة من Basic Diet أو مصدر موثوق.
- **HYPOTHESIS**: افتراض نريد اختباره.
- **DECISION**: قرار تم اعتماده.
- **TODO**: شيء ما زال يحتاج بيانات أو تنفيذ.

## الهدف النهائي للصفحة

الصفحة ليست متجرًا مزدحمًا ولا نسخة من المنافسين. وظيفتها الأساسية هي:

**إقناع الزائر بفهم Basic Diet والثقة به ثم الانتقال إلى تحميل التطبيق أو بدء الاشتراك.**
